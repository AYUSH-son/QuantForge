# QuantForge Design System

## 1. Visual Identity

QuantForge is a:

**Professional HFT terminal + futuristic quant laboratory**

The interface should feel:
- Technical
- Precise
- Fast
- Analytical
- Premium
- Futuristic

Avoid excessive cyberpunk effects or visual clutter.

---

## 2. Color System

### Base
- Near-black background
- Dark charcoal panels
- Dark borders

### Primary
- White / light gray text

### Main Accent
- Electric green

Used for:
- Progress
- Success
- Active states
- Positive performance

### Secondary Accent
- Subtle cyan / blue

Used for:
- Information
- Secondary highlights
- System indicators

### Warning
- Amber

### Negative / Market
- Red

Used for:
- Errors
- Losses
- Negative market movement

Colors should remain consistent across the entire application.

---

## 3. Typography

Typography should be:
- Clean
- Technical
- Highly readable

Large headings should be strong and simple.

Small technical labels may use uppercase text and letter spacing.

Readability is more important than visual novelty.

---

## 4. Layout

The application should use a consistent layout.

Main structure:

Sidebar
+
Top Header
+
Main Content Area

The content area should support:
- Cards
- Tables
- Charts
- Code
- Mathematical formulas
- Data visualizations
- Interactive panels

---

## 5. Background

The background is an independent visual layer.

Initial background:
- Near-black
- Subtle technical grid
- Very subtle ambient glow
- Minimal motion

The background must never interfere with reading or interaction.

The background should remain behind the complete application.

Future background styles may include:
- Grid
- Particles
- Data streams
- Scan lines
- Other lightweight effects

---

## 6. Components

Components should use a consistent visual language.

### Cards
- Dark surface
- Thin border
- Subtle depth
- Moderate corner radius

### Buttons
- Clear states
- Simple hover effects
- Strong readability

### Panels
- Dark background
- Structured spacing
- Clear hierarchy

### Tables
- Dense but readable
- Aligned numerical data
- Clear headers

### Charts
- Minimal decoration
- Easy to read
- Consistent meaning for colors

---

## 7. Animation

- Initial animation should be subtle and lightweight.
- The system must support multiple animation styles later.
- Animation intensity, speed, and types should eventually be configurable.
- Reduced-motion and performance options should be supported.
- Animations must never reduce usability or readability.

Possible future animation modes:
- Minimal
- Ambient
- Dynamic
- Performance

---

## 8. Keyboard Shortcuts

QuantForge should eventually support global keyboard shortcuts.

Examples:

- Dashboard
- CP Engine
- Math Lab
- AI Forge
- HFT Lab
- Command menu
- Timer
- Quick actions

Shortcut definitions must be centralized.

Shortcuts should eventually be user-editable.

---

## 9. Responsiveness

QuantForge should work on:
- Desktop
- Laptop
- Smaller screens

The primary design target is desktop because the application will eventually contain:
- Code
- Tables
- Charts
- Order books
- Benchmarks
- Technical information

---

## 10. Accessibility and Performance

The interface must remain usable even with visual effects disabled.

Requirements:
- Adequate contrast
- Readable text
- Keyboard accessibility
- Reduced-motion option
- Performance-conscious animations

---

## 11. Design Principle

QuantForge should look futuristic without becoming distracting.

The application exists to help the user:

**Learn → Practice → Build → Measure → Improve**

Function always comes before decoration.
